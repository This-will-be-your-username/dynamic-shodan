Shodan only crawls each address every few days, so right after a change it mostly knows about the previous holder. This asks for an on-demand scan of the new IP and fetches the results when it's done. Each rescan uses 1 scan credit (included with paid plans; see Test API key for your balance). You can also request one from the dashboard.

Dynamic DNS

The DDNS name that always points at your current public IP.

Query this server directly to avoid stale local caches or split-horizon answers. Use the DDNS provider's authoritative nameserver for the fastest updates.

Schedule

Shodan is always re-queried right away when your IP changes. A shorter IP check interval narrows the window in which ownership is uncertain.
